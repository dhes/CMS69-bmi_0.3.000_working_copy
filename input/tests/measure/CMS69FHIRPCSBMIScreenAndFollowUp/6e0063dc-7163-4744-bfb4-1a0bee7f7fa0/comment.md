SNOMED|895451009 Referral to service declined by subject (situation) is mentioned in the markdown element of the test MeasureReport of this patient,but is not used in the actual patient ServiceRequest. Rather it is Treatment Not Tolerated. 

This patient has no BMI recorded, and has a referral to a GP presumably to get a BMI recorded. They refused the referral, which was presumably to a doctor who would perform a BMI exam. I guess the scenario is a Practitioner is someone who does not routinely weigh patients (dermatologist?) but believe patient is under/over-weight. In which case this would be Reason no Referral for High/Low BMI follow-up. But then if this Practitioner action is because patient says has never been screened for over/under weight, it would be a Reason no Follow Up For BMI Screening. So it's a little non-sensical. In any case, according to the CQL it should return the ServiceRequest resource as "Medical Reason For Not Documenting A Follow Up Plan For Low Or High BMI".
